# Proxy de evaluación

**Requisito:** Node.js 24. Ejecutar los comandos desde la carpeta del proxy.

**Instalar dependencias:**

```powershell
npm ci
```

**Iniciar el proxy:**

```powershell
npm start       # sin demora
npm start 5000  # 5.000 ms de demora solo en el canje
```

Para cambiar la demora, detener el proxy con `Ctrl+C` y volver a iniciarlo.
